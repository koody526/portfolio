# 구대연 | 개발 포트폴리오

백엔드·게임 개발 프로젝트와 학습 경험을 정리합니다. 팀 프로젝트에서는 팀 산출물과 개인 수행을 구분하고, AI 도움을 활용한 작업은 해당 사실을 함께 설명합니다.

## ONE-TAP

타키온을 레퍼런스로 기획한 4인 팀 Unity 게임입니다. 게임 개발과 itch.io Windows 버전 공개를 진행했고, KPI 보고서 작성·발표와 14개 대학 대상 홍보를 수행했습니다. 개발 전반에서 AI를 활용했습니다.

- 원본에서 확인한 기술: Unity, C#, Firebase
- 원본 에디터: Unity 6000.2.6f1
- 배포: [itch.io Windows 버전](https://koody526.itch.io/one-tap)
- 기능: 플레이어 이동, 장애물, 점수·일시정지, Firebase 연동 구성
- 소스 공개: 팀 공유 범위와 에셋 이용조건 확인 후 결정

### KPI 보고

2025-11-06~12(7일)과 11-13~18(6일)의 일평균 DAU는 약 4.43명과 11.33명입니다. 평균의 비율은 약 2.56배입니다. 팀 게임의 일평균 DAU를 비교한 값입니다.

## Pygame Snake

AI 도움을 활용한 Python/Pygame 개인 게임 실습입니다. 객체지향 구조로 이동·벽/자기 충돌·방향 입력 제한·먹이 재배치·WIN 상태를 다룹니다. 소스 공개는 별도로 준비 중입니다.

## NEON SYNC

HTML/CSS/JavaScript로 만든 자판기 화면 실습입니다. 잔액·재고·품절과 색상 패턴 입력에 따른 구매 조건을 다룹니다. 실제 결제·서버 인증 시스템은 아닙니다. 2026.11 AI 협업으로 잔액 부족·인증 전 구매·정상 구매·잔돈 반환·품절 등 화면 점검 6건을 진행했습니다. 소스 공개는 별도로 준비 중입니다.

## 화해법정

갈등 조정 서비스의 사용자 흐름과 백엔드 구성안을 공동 조사·설계하고 문서화한 팀 프로젝트입니다. 설계 경험으로 소개하며 실제 백엔드 구축·운영 실적으로 표현하지 않습니다.

## 게임 로그 DB 설계 연습

2026.11 AI 협업으로 게임 로그 ER 모델과 SQL을 설계하고, 합성 데이터로 SQLite의 참조 무결성·시간/점수 제약·DAU/랭킹 조회를 검증했습니다. 13개 테스트를 통과한 신규 학습 예제입니다.

- [game-db-design-practice](https://github.com/koody526/game-db-design-practice): ER 그림, DDL, 더미 데이터, 조회 SQL, 검증 코드
